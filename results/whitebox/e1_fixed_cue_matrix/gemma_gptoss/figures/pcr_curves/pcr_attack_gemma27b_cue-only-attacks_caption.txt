pcr_attack_gemma27b_cue-only-attacks: PCR@k, Gemma-3-27B-IT, Cue-only attacks. Each panel plots exactly one attack condition (one per row) against its baseline (Clean) for one dataset. Y-axis fixed 0-100% across every panel (not rescaled per panel, so effect sizes stay comparable); x-axis upper bound is computed per panel as the last step any plotted condition was still below 99.5% PCR (+2 steps margin), trimming the flat post-saturation tail without altering the y-scale. Curves are monotone (PCHIP) interpolations of the true step-wise pcr_stepwise.csv values -- no data beyond the observed step range (1-30) is implied or extrapolated. Denominator = pcr_eligible runs (canonical_completion.py definition). Source: data/pcr_stepwise.csv.
