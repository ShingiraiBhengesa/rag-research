## Before writing prose

1. Read `MASTER_RESULTS.md` in full, including every `_TODO(human)_` block.
2. Check `data/VALIDATION_GATES.csv` -- do not write Chapter 5 text against a bundle with a failing gate.
3. Every number you write in the thesis should trace back to a specific cell in one of the `data/*.csv` files or a specific figure/table file -- if you cannot point to the source, do not write the number.
4. Answer accuracy numbers are pre-adjudication (spec 3.3) until the blinded review of `needs_adjudication_flag == True` rows is complete -- say so explicitly wherever an accuracy number appears, not only in a footnote.
